# LocalReader 📚

A modern, feature-rich ebook reader web application built with React and Vite.

## ✨ Features

- 📖 **Comfortable Reading** - Clean, customizable reading interface with adjustable font size, line height, and page margins
- 📚 **Chapter Navigation** - Easy navigation between chapters with click zones and keyboard controls
- 🎨 **Customizable Themes** - Multiple theme options including background color, text color, and accent colors
- 📑 **Table of Contents** - Built-in chapter list with sorting options
- 💾 **Progress Saving** - Automatically saves your reading progress
- 🔒 **Screen Lock** - Lock screen to prevent accidental touches
- ⛶ **Fullscreen Mode** - Immersive reading experience
- 📱 **Responsive Design** - Works great on desktop and mobile devices

## 🚀 Quick Start

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```

## 🎯 Usage

### Reading Controls

- **Click left/right side** of the screen to navigate between chapters
- **Click center** to toggle control elements visibility
- **Use arrow keys** (← →) to switch chapters
- **Double-click** center area to show/hide controls

### Settings

Customize your reading experience:
- Font size adjustment
- Line height adjustment
- Page margin control
- Background color selection
- Text color selection
- First line indent toggle
- Paragraph spacing control
- Chapter title highlight

### Chapter List

- Click the chapter list button to view all chapters
- Toggle between ascending/descending order
- Click any chapter to jump directly to it

## 🛠️ Tech Stack

- **React** - UI library
- **Vite** - Build tool and development server
- **CSS** - Styling with CSS variables for theming
